# Your Assignment: Split 1 — runtime-core

This zip contains the FULL working CampusBot project so you can run and
test everything locally. You only need to EDIT the files listed below —
everything else is here so the app runs end-to-end while you work.

## Files you own for this lab:
- main.py
- app/runtime/orchestrator.py

## How to work
1. Extract this zip.
2. Copy 'project/' next to your own 'CampusBot Launcher.app' (from the
   course package you already have) so paths line up.
3. Edit ONLY the files listed above.
4. Test locally: stop CampusBot, relaunch CampusBot Launcher.app, verify
   your changes work in the browser.
5. Run the test suite:
     CAMPUSBOT_SOURCE_ROOT="$PWD" python3 tests/main.py
6. git init, commit, push to your own GitHub repo.

## Do not edit
Files outside your list belong to teammates. If you think a shared file
(like app/skills/base.py or app/runtime/router.py) needs to change,
flag it to the team instead of editing it directly — everyone else's
code depends on that contract staying stable.

Team's final step: merge everyone's owned files back into one project/
folder before submission.
